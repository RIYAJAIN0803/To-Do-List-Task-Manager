# To-Do List & Task Manager

A responsive task management website built using HTML, CSS, and JavaScript.

## Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Organize tasks into To Do, In Progress, and Done
- Filter tasks by status
- Save tasks using browser localStorage

## Technologies Used
- HTML5
- CSS3
- JavaScript
- localStorage
